Access Methods

Choose How People Enter

Different properties require different ways of controlling access. Nexpak can help you select suitable access methods based on security, convenience, user numbers and the type of entrance being protected.

01
BIOMETRIC

Fingerprint Access

Identify authorised users using biometric fingerprint credentials where supported by the access-control system.

  • User-specific credentials
  • No physical key required
  • Suitable for controlled environments
02

Cards & Tags

RFID cards and proximity tags provide a convenient method of identifying authorised users at compatible readers.

  • Quick user identification
  • Easy to issue to multiple users
  • Suitable for offices and facilities
03
PIN ACCESS

Keypad Entry

Users can enter a programmed PIN through a compatible keypad or access-control terminal.

  • No card required
  • Useful for selected users
  • Suitable for doors and gates
04
MOBILE

Mobile Access

Compatible systems may allow authorised users to interact with access-control equipment using mobile devices.

  • Convenient credential option
  • Reduced reliance on physical cards
  • Depends on system compatibility

REMOTE ACCESS

Remote Entry

  • Convenient vehicle access
  • Works with compatible automation
  • Ideal for selected entrances

  • Visitor identification
  • Voice or video communication
  • Suitable for controlled entrances

System Components

The Technology Behind Controlled Entry

A complete access-control system is made up of several components working together. Each part performs a specific function, from identifying the user to releasing the door or gate.

01
CONTROL

Access Controller

The controller processes access information and manages connected entry points according to the configuration of the system.

The brain of the system
02
IDENTIFICATION

Access Reader

Readers identify credentials such as cards, tags, PINs or other supported authentication methods before access is authorised.

Identifies the user
03
PHYSICAL SECURITY

Electric Lock

Compatible electric locking hardware can secure a door while allowing authorised access to release the locking mechanism.

Secures the entrance
04
EXIT

Exit Button

Exit devices can provide a convenient method for authorised occupants to release a controlled door from the secure side.

Controls internal exit
05
POWER

Power Supply

A suitable power supply provides the required electrical power to compatible access-control equipment and locking hardware.

Powers the system
06
CREDENTIALS

Cards, Tags & PINs

Credentials provide users with the means of identifying themselves to the access-control system.

Identifies authorised users
07
MONITORING

Door Position Sensor

Compatible door sensors can provide information about whether a controlled door is open or closed.

Monitors door status
08
SAFETY

Emergency Release

Where required, suitable emergency release equipment can provide an additional means of releasing a controlled exit during an emergency.

Supports emergency egress
