THE SYSTEM BEHIND THE PROTECTION

Professional Alarm Components

A reliable alarm installation is more than simply installing a siren. The system combines a control panel, detection devices, user controls, communication equipment and backup power to create a coordinated security solution.

SYSTEM CORE

Alarm Control Panel

The control panel is the central processing unit of the alarm system. It receives signals from connected detectors and manages alarm events, zones, users and system functions.

Zone management Event processing User management System programming

Keypads & User Controls

Keypads provide authorised users with a convenient way to arm, disarm and manage the alarm system.

Secure user access

Motion Detectors

Motion detectors monitor protected areas and identify movement within their detection field.

Interior movement detection

Magnetic Door Contacts

Magnetic contacts monitor doors, windows and other opening points. Separating the contact can trigger an alarm condition.

Entry-point protection

Sirens & Sounders

Audible and visual alarm devices provide local notification when an alarm event occurs.

Audible alarm notification

Backup Batteries

Backup power helps keep the alarm system operational during a mains power interruption, subject to system configuration and battery condition.

Backup power protection

Communication Modules

Compatible communication modules can allow alarm events and system information to be transmitted through supported communication networks.

Remote event communication

Panic Buttons

Panic devices provide an intentional manual method of initiating an alarm event when immediate assistance is required.

Manual emergency activation
