01

Principles of System Design

Professional electric-fence design begins before the first component is purchased or installed.

The designer must understand the property, security objective, environmental conditions, perimeter structure, access points and interaction with other security systems.

A Professional Design Considers

  • Site layout
  • Perimeter configuration
  • Security objectives
  • Risk areas
  • Fence construction
  • Gates and access points
  • Electrical supply
  • Earth system
  • Environmental conditions
  • Alarm requirements
  • CCTV coverage
  • Monitoring requirements
  • Applicable standards and regulations

Design Before Installation

A well-designed system reduces installation problems, improves maintainability and provides a more predictable security outcome.

The System Must Be Designed As A Whole

The energizer, conductors, insulators, earth system, zoning, gates, alarm interfaces and monitoring equipment should be considered as parts of one security system.

Professional Principle

Do not design the fence first and attempt to solve the security requirements afterwards. Define the security requirement first, then design the system around it.

02

Defining the Security Objective

Before designing an electric-fence system, the technician or security professional must understand what the system is intended to achieve.

Questions To Establish

  • What area must be protected?
  • What type of intrusion is the system intended to detect or deter?
  • Which perimeter sections represent the greatest risk?
  • Where are the normal access points?
  • Are there pedestrian or vehicle gates?
  • Are there vulnerable structures near the perimeter?
  • Is rapid alarm notification required?
  • Does the customer require integration with CCTV or another security system?

Detection And Deterrence

An electric fence can contribute to both physical deterrence and intrusion detection. The design should clearly identify the intended function of the installation.

Security Priorities

Not every section of a property necessarily presents the same security risk.

Professional design identifies critical areas and ensures that the system architecture supports the required level of protection.

Never Design From Assumptions

A technician should not assume that every property has the same security requirements. Site-specific conditions must be assessed before the system is designed.

03

Site & Perimeter Analysis

Site analysis converts the physical property into information that can be used for system design.

Inspect The Property

  • Property boundaries
  • Existing walls
  • Existing fences
  • Slopes and changes in level
  • Gates
  • Buildings
  • Trees and vegetation
  • Drainage areas
  • Electrical infrastructure
  • Communication infrastructure
  • Potential external interference

Perimeter Walk

A complete perimeter walk should be performed before finalising the design.

This allows the designer to identify physical conditions that may not be visible on a basic property drawing.

Measurements

Relevant perimeter dimensions should be established as accurately as reasonably possible.

Measurements influence material quantities, zoning decisions, cable routing, equipment placement and installation planning.

Field Rule

Walk the perimeter before designing the perimeter.

04

Perimeter Architecture

Perimeter architecture describes how the physical security boundary is constructed and how the electric-fence system interacts with that boundary.

Common Perimeter Considerations

  • Wall-mounted systems
  • Free-standing fence structures
  • Existing palisade structures
  • Security mesh
  • Combination wall and fence systems
  • Sloped boundaries
  • Irregular property boundaries

Structural Condition

The supporting structure must be suitable for the proposed installation.

Cracked walls, unstable posts, damaged fencing or other structural defects should be identified before installation begins.

Alignment

The perimeter layout should provide a consistent and maintainable conductor arrangement while accommodating the physical shape of the property.

Changes In Level

Slopes and changes in elevation require careful planning so that conductor spacing, mechanical support and overall system configuration remain appropriate.

Never Compromise The Structure

An electrically effective fence is still a poor security installation if its supporting structure is unstable or unsuitable.

05

Risk-Based Design

Professional security design should be based on the actual risks associated with the property rather than applying the same design to every site.

Risk-based design considers the likelihood of intrusion, the consequences of a breach and the characteristics of the protected property.

Factors To Consider

  • Property location
  • Property use
  • Perimeter accessibility
  • Existing security measures
  • Vulnerable areas
  • Access points
  • Environmental conditions
  • Customer security requirements
  • Required response and monitoring

Identify Vulnerable Areas

Some perimeter sections may be easier to approach, conceal an intruder more effectively or provide access to particularly sensitive areas.

These areas should receive appropriate attention during the security design process.

Risk Is Not Static

Security risks can change when the property, surrounding environment, access arrangements or use of the premises changes.

Professional Principle

Design the security system around the risk, not simply around the perimeter length.

06

Advanced Zoning

Zoning divides a larger electric-fence installation into manageable sections for monitoring, fault identification and system management.

Why Use Zones?

  • Improve fault localisation
  • Improve alarm identification
  • Simplify maintenance
  • Assist system expansion
  • Improve operational visibility
  • Allow different perimeter areas to be managed appropriately

Zone Boundaries

Zone boundaries should be planned according to the physical layout, security requirements and equipment capabilities.

Avoid Unnecessary Complexity

More zones do not automatically mean a better system.

Excessive complexity can increase installation, maintenance and diagnostic requirements.

Logical Zoning

Useful zoning may follow natural property divisions such as front, rear, side boundaries, vehicle entrances or other meaningful security areas.

Zoning Must Match The Equipment

The number and configuration of zones must remain within the capabilities of the selected equipment and system architecture.

07

Gates & Access Points

Gates are among the most important areas in perimeter security design because they create controlled openings in an otherwise continuous boundary.

Gate Design Considerations

  • Gate type
  • Gate movement
  • Electric-fence termination
  • Insulation requirements
  • High-voltage cable routing
  • Gate access frequency
  • Alarm requirements
  • Mechanical clearance
  • Maintenance access

Moving Gates

A moving gate requires particular attention to the transition between fixed and moving sections of the perimeter.

The design must accommodate movement without creating unsafe conditions or compromising the intended electrical arrangement.

Vehicle Entrances

Vehicle gates may require integration with gate-automation equipment, access control, intercom systems and alarm monitoring.

Pedestrian Access

Pedestrian gates should be considered as part of the complete perimeter-security design rather than treated as an afterthought.

Gate Areas Require Extra Attention

Frequent movement, mechanical wear and repeated access can make gates more demanding to maintain than fixed perimeter sections.

08

Security System Integration

Modern perimeter protection often combines electric fencing with other security technologies.

The objective is to create a coordinated security solution rather than a collection of independent devices.

Common Integration Partners

  • Intrusion alarm systems
  • CCTV
  • Access control
  • Gate automation
  • Intercom systems
  • Remote monitoring
  • Security control rooms

Integration Planning

Before connecting systems together, determine what information needs to be transferred and what response should occur when an event is detected.

Alarm Events

An electric-fence alarm may be used to trigger or inform other security systems depending on the equipment and system design.

Avoid False Integration

Integration should have a defined purpose. Connecting equipment without understanding the required inputs, outputs and responses can create unreliable or confusing security behaviour.

Think In Systems

The strongest security solutions are designed around how the systems work together, not simply around how many devices are installed.

09

CCTV Integration

CCTV can complement an electric-fence system by providing visual information when a perimeter event occurs.

The electric fence can provide an indication that an event has occurred, while CCTV can assist in determining what is happening at the affected location.

CCTV Integration Objectives

  • Identify the affected perimeter area
  • Provide visual verification
  • Assist security response
  • Support incident investigation
  • Improve situational awareness

Camera Positioning

Cameras should be positioned according to the required field of view, lighting conditions, mounting environment and security objectives.

Event Association

Where equipment supports it, a fence alarm or zone event may be associated with a relevant camera or recording system.

This allows the operator to investigate the correct area instead of searching through the entire property.

Night-Time Performance

CCTV integration must consider night-time visibility. A camera that provides excellent daytime coverage may not provide the same information under darkness or changing illumination.

Do Not Assume CCTV Equals Verification

Camera performance depends on positioning, lighting, image quality, field of view and equipment configuration. Integration should be tested under realistic operating conditions.

10

Alarm Integration

Electric-fence systems can form part of a wider intrusion alarm solution where compatible equipment and system architecture permit.

Alarm Integration Considerations

  • Event detection
  • Zone identification
  • Alarm inputs
  • Relay or communication interfaces
  • Alarm response
  • Monitoring requirements
  • Event logging

Understand The Signal

Before integrating two systems, the technician must understand what signal is being produced, what equipment receives it and what response is expected.

Alarm Conditions

Different systems may distinguish between normal operation, alarm conditions, power failures, communication faults and other events.

These conditions should be correctly identified during system design and commissioning.

False Alarm Management

Repeated nuisance alarms can reduce confidence in a security system and may lead operators to ignore genuine events.

The cause of repeated alarms should therefore be investigated rather than simply suppressing the alarm condition.

Professional Principle

A security alarm is only useful when the system can reliably communicate the event and the response process is clearly understood.

11

Remote Monitoring

Remote monitoring allows relevant system events or conditions to be communicated to an operator or monitoring service away from the protected property.

Possible Monitoring Information

  • Fence alarm events
  • Zone information
  • Power failures
  • Backup battery conditions
  • Communication failures
  • Equipment faults
  • System status

Communication Path

A monitored system depends on a communication path between the protected premises and the receiving system.

The design should therefore consider the reliability and limitations of the selected communication method.

Monitoring Is A Process

Sending an alarm is only one part of the solution. There must also be a defined process for receiving, assessing and responding to the event.

Communication Failure

The security system should be assessed for what happens if its normal communication path becomes unavailable.

Do Not Promise Response Times

Technicians should not make unsupported claims about monitoring or emergency response times. These depend on the monitoring provider, response arrangements, equipment and service agreement.

12

Professional Design Documentation

A professional electric-fence project should be supported by clear documentation.

Documentation helps communicate the intended system design, supports installation and commissioning, and provides a useful reference for future maintenance.

Design Documentation May Include

  • Site information
  • Perimeter layout
  • Fence zones
  • Gate locations
  • Energizer location
  • High-voltage cable routes
  • Earth-system information
  • Equipment schedules
  • Alarm interfaces
  • CCTV integration points
  • Monitoring requirements
  • Relevant notes and assumptions

Site Drawing

A clear site drawing can show the relationship between the perimeter, fence zones, gates, equipment and other security systems.

Equipment Schedule

An equipment schedule provides a structured record of the major components included in the system.

Design Assumptions

Important assumptions should be recorded rather than left to memory.

Examples include existing infrastructure, customer requirements, access arrangements and conditions identified during the site assessment.

Professional Principle

If another competent technician cannot understand your design from the documentation, the documentation is not complete enough.

Protect Security Information

System drawings, equipment locations, access information and monitoring details can contain sensitive security information. Documentation must be stored and shared responsibly.

13

Professional Design Workflow

A professional electric-fence design should follow a structured process from the initial customer consultation through to final documentation.

Recommended Design Sequence

  1. Understand the customer's security requirements.
  2. Conduct a site assessment.
  3. Identify perimeter risks and vulnerable areas.
  4. Assess the existing perimeter structure.
  5. Identify gates and access points.
  6. Determine appropriate fence configuration.
  7. Develop the zoning arrangement.
  8. Determine equipment requirements.
  9. Plan power and relevant earth-system requirements.
  10. Plan high-voltage cable routes.
  11. Determine alarm, CCTV and monitoring integration requirements.
  12. Review the design against applicable requirements.
  13. Prepare documentation and equipment schedules.
  14. Review the final design before installation.

Design Review

Before installation begins, the proposed design should be reviewed to identify omissions, conflicts or impractical installation conditions.

Installation Planning

The design should provide enough information for the installation team to understand the intended system without relying on assumptions.

Design Principle

Good design reduces problems before they reach the installation stage.

14

Design Quality Review

Before approving an electric-fence design, the designer should conduct a structured review.

Design Review Checklist

  • ☐ Customer security objective identified
  • ☐ Site assessment completed
  • ☐ Perimeter structure assessed
  • ☐ Vulnerable areas identified
  • ☐ Gates and access points considered
  • ☐ Fence configuration defined
  • ☐ Zones logically planned
  • ☐ Energizer requirements established
  • ☐ Power requirements considered
  • ☐ Earth-system requirements considered
  • ☐ High-voltage cable routes planned
  • ☐ Alarm integration considered
  • ☐ CCTV requirements considered
  • ☐ Monitoring requirements considered
  • ☐ Maintenance access considered
  • ☐ Documentation prepared
  • ☐ Applicable standards and regulations considered

Maintainability

A good design must allow technicians to inspect, test and maintain the system throughout its service life.

Equipment should therefore be positioned and documented with future maintenance in mind.

Do Not Design Only For Installation Day

A system that is difficult to maintain can become expensive and unreliable over time. Design for the complete lifecycle of the installation.

15

Professional Design Principles

The strongest electric-fence installations are based on a combination of security effectiveness, electrical performance, safety, maintainability and compliance.

Five Design Priorities

  1. Security
    The system must address the identified security objective.
  2. Safety
    The design must consider people, property and safe operation.
  3. Reliability
    Equipment and system architecture should support dependable operation.
  4. Maintainability
    Future inspection, testing and repair should be practical.
  5. Compliance
    The installation must be designed and implemented in accordance with applicable requirements.

Avoid Over-Engineering

A professional system should be appropriately designed for the property and security requirement.

Adding unnecessary equipment or complexity does not automatically improve security.

Avoid Under-Design

The opposite problem is designing a system that does not adequately address the identified security risks.

The Right Question

Do not ask, "How much equipment can we install?"

Ask, "What system is appropriate for the security requirement, the property and the applicable requirements?"
