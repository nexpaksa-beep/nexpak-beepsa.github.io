01

Principles of System Design

Professional electric-fence design begins before the first component is purchased or installed.

The designer must understand the property, security objective, environmental conditions, perimeter structure, access points and interaction with other security systems.

A Professional Design Considers

  • Site layout
  • Perimeter configuration
  • Security objectives
  • Risk areas
  • Fence construction
  • Gates and access points
  • Electrical supply
  • Earth system
  • Environmental conditions
  • Alarm requirements
  • CCTV coverage
  • Monitoring requirements
  • Applicable standards and regulations

Design Before Installation

A well-designed system reduces installation problems, improves maintainability and provides a more predictable security outcome.

The System Must Be Designed As A Whole

The energizer, conductors, insulators, earth system, zoning, gates, alarm interfaces and monitoring equipment should be considered as parts of one security system.

Professional Principle

Do not design the fence first and attempt to solve the security requirements afterwards. Define the security requirement first, then design the system around it.

02

Defining the Security Objective

Before designing an electric-fence system, the technician or security professional must understand what the system is intended to achieve.

Questions To Establish

  • What area must be protected?
  • What type of intrusion is the system intended to detect or deter?
  • Which perimeter sections represent the greatest risk?
  • Where are the normal access points?
  • Are there pedestrian or vehicle gates?
  • Are there vulnerable structures near the perimeter?
  • Is rapid alarm notification required?
  • Does the customer require integration with CCTV or another security system?

Detection And Deterrence

An electric fence can contribute to both physical deterrence and intrusion detection. The design should clearly identify the intended function of the installation.

Security Priorities

Not every section of a property necessarily presents the same security risk.

Professional design identifies critical areas and ensures that the system architecture supports the required level of protection.

Never Design From Assumptions

A technician should not assume that every property has the same security requirements. Site-specific conditions must be assessed before the system is designed.

03

Site & Perimeter Analysis

Site analysis converts the physical property into information that can be used for system design.

Inspect The Property

  • Property boundaries
  • Existing walls
  • Existing fences
  • Slopes and changes in level
  • Gates
  • Buildings
  • Trees and vegetation
  • Drainage areas
  • Electrical infrastructure
  • Communication infrastructure
  • Potential external interference

Perimeter Walk

A complete perimeter walk should be performed before finalising the design.

This allows the designer to identify physical conditions that may not be visible on a basic property drawing.

Measurements

Relevant perimeter dimensions should be established as accurately as reasonably possible.

Measurements influence material quantities, zoning decisions, cable routing, equipment placement and installation planning.

Field Rule

Walk the perimeter before designing the perimeter.

04

Perimeter Architecture

Perimeter architecture describes how the physical security boundary is constructed and how the electric-fence system interacts with that boundary.

Common Perimeter Considerations

  • Wall-mounted systems
  • Free-standing fence structures
  • Existing palisade structures
  • Security mesh
  • Combination wall and fence systems
  • Sloped boundaries
  • Irregular property boundaries

Structural Condition

The supporting structure must be suitable for the proposed installation.

Cracked walls, unstable posts, damaged fencing or other structural defects should be identified before installation begins.

Alignment

The perimeter layout should provide a consistent and maintainable conductor arrangement while accommodating the physical shape of the property.

Changes In Level

Slopes and changes in elevation require careful planning so that conductor spacing, mechanical support and overall system configuration remain appropriate.

Never Compromise The Structure

An electrically effective fence is still a poor security installation if its supporting structure is unstable or unsuitable.
