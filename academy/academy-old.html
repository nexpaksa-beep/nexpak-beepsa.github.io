Curriculum

Built around the complete electric-fencing lifecycle.

The curriculum progresses from engineering fundamentals into design, installation, testing, diagnostics, compliance and professional practice.

MODULE 01

Electric Fence Engineering Principles

Voltage, current, resistance, energy, pulses, Joules, loading, leakage and electrical performance.

MODULE 02

Electric Fence System Architecture

Understand the complete architecture of a professional electric-fence system, including energizers, conductors, earthing, protection and system integration.

MODULE 03

System Design

Learn how professional electric-fence systems are designed around property requirements, security objectives, site conditions and system performance.

MODULE 04

Practical Fence Construction

Practical construction principles covering fence structures, posts, conductors, clearances, mechanical strength and professional installation.

MODULE 05

Energizers

Energizer technology, selection, output characteristics, loading, applications and professional installation considerations.

MODULE 06

South African Compliance

Understand South African requirements, standards, regulations, certification principles and professional responsibilities.

MODULE 07

Advanced System Design

Develop advanced system designs for more demanding properties, applications, layouts and security requirements.

MODULE 08

Advanced Installation Techniques

Advanced installation methods, difficult site conditions, system integration, cable routing and professional installation practice.

MODULE 09

Testing, Fault-Finding & Troubleshooting

Learn systematic testing, fault identification, electrical diagnosis and professional troubleshooting techniques.

MODULE 10

Maintenance, Service & System Performance

Preventative maintenance, servicing, performance checks, inspections and professional system upkeep.

MODULE 11

Advanced System Design & Security Planning

Advanced security planning, system architecture, risk assessment, integration and professional design decisions.

MODULE 12

Professional Project Planning & Installation Preparation

Site preparation, project planning, equipment requirements, documentation, scheduling and installation readiness.

MODULE 13

System Diagnosis, Professional Installation Practice & Commissioning

System diagnosis and fault-finding, professional installation practice, commissioning procedures and the standards required to complete a professional installation.

MODULE 14

System Maintenance & Preventative Servicing

Develop professional maintenance routines, preventative servicing procedures, inspections and long-term system performance practices.

MODULE 15

Advanced Fault Finding & Technical Diagnosis

Advanced diagnostic methods for identifying complex system faults, analysing symptoms and restoring reliable system operation.

MODULE 16

System Commissioning, Verification & Handover

Verify completed installations, perform final testing, confirm system performance and prepare the system for professional customer handover.

MODULE 17

Advanced Security System Design & Integration

Advanced security system architecture, integration of security technologies, system planning and professional security solutions.

FINAL EXAM

Professional Security Technician Examination

Complete the comprehensive 50-question examination covering the knowledge, technical principles, installation practices and professional standards presented throughout the Academy.
